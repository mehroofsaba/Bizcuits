# Contributing to Bizcuits

Thanks for helping! 

- **Bugs:** open an issue with what you did, what you expected, and what happened. Never paste real customer data.
- **Ideas:** open an issue describing the problem it solves for small businesses.
- **Pull requests:** keep them focused. Run `cd backend && pytest` and `cd frontend && npm test`. If you change the frontend, run `npm run build` and commit `frontend/dist` (the free Render deploy serves it).
- **Principles:** AI output is only a suggestion; numbers come from code; never show invented data as real; keep copy short; keep keyboard focus and reduced-motion support working.
